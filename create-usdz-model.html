🪑 Generate Ergonomic Zones 3D Model

This tool creates a 3D model of the ergonomic desk zones for iOS AR Quick Look.

📋 Instructions

Step 1: Click "Generate 3D Model" to create the zones
Step 2: Click "Download GLB File" to save the model
Step 3: Convert GLB to USDZ:
  • Option A (Mac): Use Reality Converter (free from Apple)
  • Option B (Online): Use Aspose GLB to USDZ Converter
  • Option C (Command line): Use xcrun usdz_converter model.glb desk-ergonomics.usdz
Step 4: Save the USDZ file as desk-ergonomics.usdz in the models/ folder
