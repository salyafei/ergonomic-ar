📷 Camera Permission Required

This AR experience needs camera access to detect surfaces and place objects.

iOS Safari:

  1. Tap the "aA" icon in the address bar
  2. Select "Website Settings"
  3. Enable "Camera"
  4. Reload the page

Android Chrome:

  1. Tap "Allow" when prompted
  2. If blocked, tap the lock icon in address bar
  3. Enable "Camera" permission
  4. Reload the page
