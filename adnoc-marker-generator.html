🎯 ADNOC AR Marker Generator

Create a custom AR marker using the ADNOC logo

📌 Important: This tool helps you create a custom AR marker pattern file (.patt) from the ADNOC logo. The generated marker will be used for AR tracking in the Desk Ergonomics AR application.

Step 1: Download ADNOC Logo

Option A: From ADNOC Website

  1. Visit the ADNOC website:
    https://www.adnoc.ae
  2. Right-click on the ADNOC logo (usually in the top-left header)
  3. Select "Save image as..." or "Copy image"
  4. Save as adnoc-logo.png or adnoc-logo.jpg

Option B: Use AR.js Marker Generator

Visit the official AR.js marker training generator:

https://ar-js-org.github.io/AR.js/three.js/examples/marker-training/examples/generator.html
⚠️ Logo Requirements:
  • High contrast (preferably logo on white background)
  • Square or near-square aspect ratio (recommended)
  • Minimum 512x512 pixels
  • Clear, sharp image (no blur)

Step 3: Generate AR Marker Pattern

🔧 Generate Custom Marker: Use the AR.js marker generator to create a pattern file from your logo.

Using AR.js Online Generator:

  1. Visit the AR.js Pattern Marker Generator:
    https://ar-js-org.github.io/AR.js/three.js/examples/marker-training/examples/generator.html
  2. Upload your ADNOC logo image
  3. The tool will generate a marker pattern
  4. Download the generated .patt file as adnoc-marker.patt
  5. Also download the marker image (black border version) for printing
✅ Pro Tip: The generator creates both:
  • Pattern file (.patt) - Used by the AR app for tracking
  • Marker image (PNG) - Print this on paper for physical tracking

Step 4: Integrate into AR Application

A. Add Pattern File to Project:

  1. Place adnoc-marker.patt in your project's root directory
  2. Also save the printable marker image as adnoc-marker.png

B. Update index.html:

The AR application has been pre-configured to use custom markers. Simply replace the pattern file path:

📝 Note: The application code has already been updated to look for adnoc-marker.patt. Just add the file to your repository.

C. Print the Marker:

  1. Print adnoc-marker.png on white A4/Letter paper
  2. Use high quality settings (300 DPI minimum)
  3. Print at actual size (100% scale, no fitting)
  4. Laminate or protect with clear sheet
  5. Place on your desk
