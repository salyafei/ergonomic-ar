# 3D Models

Place your GLB models here.

## Recommended Tools

- **Blender** - Free 3D modeling software
- **gltf-pipeline** - For DRACO compression
- **glTF Viewer** - For testing models

## Optimization Tips

1. Use DRACO compression
2. Keep file size under 5MB
3. Use power-of-2 texture dimensions
4. Optimize polygon count
5. Bake lighting when possible
