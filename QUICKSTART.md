# ⚡ Quick Start Guide

Get up and running with Desk Ergonomics AR in 5 minutes!

## 🎯 What You Need

- 📱 Smartphone (iOS 11+ or Android 7+)
- 🖨️ Printer
- 📄 White paper (A4 or Letter)
- 🌐 Internet connection

## 🚀 3 Simple Steps

### Step 1: Deploy the App (2 minutes)

**Option A: GitHub Pages (Recommended)**

```bash
# Clone or download this repository
git clone https://github.com/your-username/ergonomic-ar.git
cd ergonomic-ar

# Push to your GitHub account
git add .
git commit -m "Initial deployment"
git push origin main

# Enable GitHub Pages in Settings → Pages → Select 'main' branch
```

Your app will be live at: `https://your-username.github.io/ergonomic-ar/`

**Option B: Instant Deploy (30 seconds)**

- Go to [netlify.com/drop](https://app.netlify.com/drop)
- Drag the project folder
- Done! Copy the URL

### Step 2: Print the Marker (1 minute)

**Download Marker:**
- Visit: https://raw.githubusercontent.com/AR-js-org/AR.js/master/data/images/hiro.png
- Right-click → Save image
- Print on white paper (high quality, 100% scale)

**Or use the app:**
1. Open your deployed app
2. Click "Download Desk Marker"
3. Follow the prompts

**Tips:**
- Use best print quality
- Black ink only (no grayscale)
- Cut out the marker
- Laminate or use sheet protector (optional but recommended)

### Step 3: Generate QR Code (1 minute)

1. **Open QR Generator:**
   - Visit: `https://your-app-url/qr-generator.html`
   - Or use any QR code generator

2. **Enter your app URL:**
   ```
   https://your-username.github.io/ergonomic-ar/
   ```

3. **Generate & Print:**
   - Click "Generate QR Code"
   - Print the QR code
   - Place it on your desk (optional - for easy access)

## 🎮 Using the App

### First Time Setup

1. **Scan QR Code** (or visit URL directly)
   - Open camera app on smartphone
   - Point at QR code
   - Tap notification to open link

2. **Place Marker**
   - Put printed marker flat on your desk
   - Center it in your workspace
   - Ensure good lighting

3. **Start AR**
   - Tap "Start AR Experience"
   - Allow camera access
   - Point camera at marker
   - See ergonomic zones appear!

### Using the Zones

**🟢 Green (Primary Zone)**
- Place keyboard, mouse, frequently used items
- Keep within easy reach

**🟡 Yellow (Secondary Zone)**
- Documents, notepad, occasional items
- Extended reach area

**🔵 Blue (Monitor Zone)**
- Position screen here
- Arm's length distance
- Top at eye level

**🔴 Red (Warning Zone)**
- Avoid placing items here
- Too close to edge

## 💡 Pro Tips

### For Best Results

1. **Lighting:**
   - Bright, even light
   - Avoid harsh shadows
   - No glare on marker

2. **Marker Quality:**
   - Print at high quality (300 DPI)
   - Use white, non-glossy paper
   - Keep marker flat and undamaged

3. **Camera Angle:**
   - Hold 40-60cm from marker
   - Angle 30-60 degrees
   - Keep marker fully visible

4. **Environment:**
   - Clear desk area
   - Stable marker placement
   - Good internet for first load

### Troubleshooting

**Marker not detected?**
- Improve lighting
- Move closer/further
- Ensure marker is flat
- Reprint at higher quality

**Camera not working?**
- Allow camera permission
- Use HTTPS URL
- Try different browser
- iOS: Use Safari (not Chrome)

**Zones not appearing?**
- Wait for marker detection
- Check marker is visible
- Ensure stable internet connection
